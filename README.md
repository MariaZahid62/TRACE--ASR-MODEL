# TRACE – English Speech Recognition

**TRACE (Transcription, Recognition and Acoustic Context Engine)** is a local, offline English speech-to-text prototype. This repository currently contains the speech-recognition component: a custom CNN + bidirectional GRU (BiGRU) acoustic model trained with Connectionist Temporal Classification (CTC), with greedy decoding for transcription.

The application provides two main areas:

- **Verified Demo Recordings:** Load selected LibriSpeech recordings and view their generated transcripts.
- **Try Your Own Audio:** Upload or record an English audio sample and view the transcription generated by the trained model.

TRACE does not call cloud speech-recognition APIs.

## Features

- Offline inference using a locally stored trained model.
- Audio upload and microphone recording through a Gradio interface.
- Audio loading with SoundFile and resampling with torchaudio.
- Log-Mel feature extraction.
- CNN + 5-layer bidirectional GRU model with CTC.
- Greedy CTC decoding.
- LibriSpeech reference recordings for a quick demo.
- 100 sample audio recordings with corresponding reference transcripts.
- Training, evaluation, and metric history files.

## Requirements

- Windows, macOS, or Linux.
- **Python 3.13** recommended (the development environment used Python 3.13.x).
- Git.
- Git LFS, required to download the model checkpoint files.
- Internet access for initial setup and downloading dependencies or the full dataset.
- A CPU is sufficient for inference. A compatible NVIDIA GPU is optional; install the appropriate PyTorch build for your hardware if using one.

## Setup on a New Computer

Run the commands from the folder where you want to place the project.

### 1. Install Git LFS

Install Git LFS from:

https://git-lfs.com/

If it is not already installed, run:

```powershell
git lfs install
```

### 2. Clone the Repository and Download the Checkpoint

```powershell
git clone https://github.com/MariaZahid62/TRACE--ASR-MODEL.git
cd TRACE--ASR-MODEL
git lfs pull
```

`git lfs pull` downloads the tracked `.pt` model files.

The application uses:

```text
checkpoints_2000/best.pt
```

If the checkpoint file is missing or Git LFS downloaded only a pointer file, check that Git LFS is installed and run `git lfs pull` again.

### 3. Create and Activate a Virtual Environment

```powershell
py -3.13 -m venv venv
```

Activate it in PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks activation for this terminal session, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

The terminal should show `(venv)` after activation.

### 4. Install Python Dependencies

Upgrade pip and install the project requirements:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**PyTorch note:** `torch` and `torchaudio` must be compatible versions. The requirements file installs both packages. If pip cannot find a compatible build for your operating system or Python version, use the official PyTorch installation selector:

https://pytorch.org/get-started/locally/

Install a matching `torch`/`torchaudio` pair for CPU or your GPU. Then run `pip install -r requirements.txt` again.

### 5. Dataset Setup

TRACE uses the LibriSpeech ASR Corpus.

Dataset source:

https://www.openslr.org/12/

The project uses the following dataset splits:

- `train-clean-100` – Training data.
- `dev-clean` – Validation data and verified demo recordings.

**Sample recordings included in the repository**

The repository includes 100 selected audio recordings from the LibriSpeech `dev-clean` dataset.

Their location is:

```text
datasets/
└── sample_audio/
    ├── 100 FLAC audio recordings
    └── metadata.csv
```

The `metadata.csv` file contains three columns:

- `file` – Audio filename.
- `utterance_id` – LibriSpeech utterance identifier.
- `transcript` – Corresponding reference transcript.

These recordings are provided for demonstration and ASR evaluation purposes. They allow users to access a small collection of audio samples and their reference transcripts without downloading the complete LibriSpeech dataset.

**Full dataset required for training and complete application functionality**

Download LibriSpeech from OpenSLR and extract the required dataset splits into the following structure:

```text
TRACE/
└── data/
    └── LibriSpeech/
        ├── train-clean-100/
        │   ├── 103/
        │   └── ...
        └── dev-clean/
            ├── 1272/
            ├── 3170/
            ├── 6313/
            └── ...
```

Do not leave the audio files inside an extra nested `LibriSpeech` or archive folder.

The application expects the demo audio under:

```text
data/LibriSpeech/dev-clean/
```

The full dataset is intentionally excluded from Git because of its size. Each team member downloads and extracts it locally.

### 6. Run the Application

From the TRACE project root, with `(venv)` active:

```powershell
python app.py
```

Open this address in your browser:

http://127.0.0.1:7860

Use **Verified Demo Recordings** to play a sample and see its generated transcript.

Use **Try Your Own Audio** to obtain a prediction from the model by uploading or recording an English audio sample.

## Evaluate the Existing Checkpoint

To evaluate the saved 2000-sample model using the configuration in the repository:

```powershell
python -m src.train --config configs/english_2000_config.yaml --eval-only --checkpoint checkpoints_2000/best.pt
```

This evaluates the existing checkpoint; it does not start a new training run.

## Sample Audio Dataset and Reference Transcripts

The repository includes 100 LibriSpeech `dev-clean` audio recordings in:

```text
datasets/sample_audio/
```

The corresponding reference transcripts are stored in:

```text
datasets/sample_audio/metadata.csv
```

The sample dataset can be used to:

1. Load an audio recording.
2. Generate a transcription using the trained TRACE ASR model.
3. Compare the predicted transcription with its reference transcript.
4. Calculate Word Error Rate (WER).

The sample recordings and reference transcripts provide a convenient way to demonstrate the ASR component without downloading the complete LibriSpeech corpus.

The sample dataset is separate from the full training and validation dataset.

## Training (Optional)

The trained checkpoint is already included through Git LFS, so a teammate does **not** need to train the model just to run the application or test inference.

If training is intentionally required, run:

```powershell
python -m src.train --config configs/english_2000_config.yaml
```

Training can take a long time on a CPU-only computer. It is not part of the normal setup process.

## Troubleshooting

**The app says the checkpoint is missing**

Run `git lfs pull` from the repository root and confirm that `checkpoints_2000/best.pt` exists and is a real model file, not a small text pointer.

**A verified demo recording cannot be found**

Confirm that the `dev-clean` split has been extracted into:

```text
data/LibriSpeech/dev-clean/
```

Check that the speaker and chapter folders are present.

**Sample audio or metadata is missing**

Confirm that the following files and folders exist:

```text
datasets/sample_audio/
datasets/sample_audio/metadata.csv
```

The metadata file should contain the corresponding reference transcripts for the 100 sample recordings.

**A Python package fails to install**

Confirm that the virtual environment is active and that Python 3.13 is being used.

For PyTorch installation issues, install a compatible `torch` and `torchaudio` pair from the official PyTorch selector.

**The app is already using port 7860**

Stop the other running TRACE application with `Ctrl + C` in its terminal before starting it again.

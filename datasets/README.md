# TRACE - Sample Audio Dataset

## Dataset Description
This directory contains 100 sample audio recordings selected from the LibriSpeech dev-clean dataset.

## Contents
- `sample_audio/`: 100 FLAC audio recordings.
- `sample_audio/metadata.csv`: Matching reference transcripts.

## Purpose
The dataset is included to demonstrate:
- Automatic Speech Recognition (ASR)
- Audio transcription using TRACE
- Word Error Rate (WER) evaluation
